
1. The file

    sagecrmws/ac2020/sage300overview.asp
  
is a sample file that can be added to the myCRM area.
To do this create a custom tab under system menus called 
    acdashboard
	
and set the values

	Caption=ERP
	Action=custom file
	Custom File:sagecrmws/ac2020/sage300overview.asp


2. 

The file

  Caption=ERP
  Action=custom file
  sagecrmws/ac2020/sage300demo.asp

is designed to be added as a tab into a Sage 300 integrated system


3. The file

  Caption=Locations
  Action=custom file
  sagecrmws/ac2020/companylocations.asp

shows all addresses for a given company and should be added under tab "companyint"
